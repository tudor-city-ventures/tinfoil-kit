        Using the kit
        
        
          
          
        • 
            Ask searches your offline books, then the AI answers and cites them as [1], [2]. Click a source to
            read it in full.
          
          • 
          
        • 
            Library lets you browse or search every book yourself: Wikipedia, medical guides, repair manuals and
            more.
          
          • 
          
        • 
            AI chat is a plain chat with the AI. It doesn't search your books, so check anything important on Ask
            or in the Library. You can attach photos there, e.g. of a broken part or a label. Use a model that reads
            photos (Inkling, Qwen, Gemma).
          
          • 
          
        • 
            Pick a different model for a second opinion. Gemma-4-E4B is the small one: use it to save
            battery.
          
          • 
          
        • 
            The first answer after picking a model is slow while it loads into memory (up to a minute). After that it's
            quick.
          
          • 
        
        
        
        Maps and directions
        
        
          
          
        • 
            Map works like a simple Google Maps: search an address or place, get driving or walking directions,
            or find the nearest hospital, pharmacy, gas station and more. Your computer has no GPS, so set
            home (bottom of the map panel) to where you are.
          
          • 
          
        • 
            You can also ask in plain words on the Ask page, e.g. "How do I get to the nearest hospital?" or "Directions
            from home to 350 Fifth Avenue, New York". The answer appears there and the route on the Map tab.
          
          • 
          
        • 
            For driving, a phone with an offline maps app (Organic Maps, or downloaded areas in Apple or Google Maps) is
            better: it has GPS and spoken turn-by-turn directions.
          
          • 
        
        
        
        Sharing with family
        
        
        
          
        
            The kit is shared on this network. On another phone or laptop on the same
            Wi-Fi, open  and type the access code
            . Or scan this with the phone's camera:
          
        
          
          
        No internet needed: a router with power, or a phone's hotspot, is enough.
        
        
        
        
          
          
        • 
            Phones and laptops on your Wi-Fi can use the kit too. In the kit's folder, run ./kit share on in
            a terminal, then start the kit again. It shows an address, an access code and a QR code to scan. No internet
            needed: a router with power, or a phone's hotspot, is enough.
          
          • 
        
        
        
        If something doesn't work
        
        
          
          
        • Close the kit's Terminal window and double-click Open Tinfoil Kit.command again.
          • 
          
        • Logs are in the logs folder, inside the kit's folder.
          • 
          
        • 
            If the AI won't start, the library still works. The Kiwix app in installers also opens the library
            files directly.
          
          • 
          
        • 
            Big models need most of the computer's memory: quit other apps. If a model still won't load, use
            Gemma-4-E4B.
