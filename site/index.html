What's inside

Plug in the drive. Double-click START-HERE. Your browser opens to four tabs.

START-HERE.command serves it all on 127.0.0.1. Running it doesn't need Python.

TAB 01

Ask

Ask in plain words, like you would online. The answer comes from the library, with numbered sources you can open. Works even with the AI off.

Retrieval over kiwix-serve's full-text search. The model writes the queries, reads the top articles and streams an answer with [n] citations. With no model, it shows the best passages.

TAB 02

AI chat

A chat AI that runs on your Mac instead of the cloud. Show it a photo of a rash, a part or a label and ask about it.

llama-server nightly, in router mode. Inkling 2 Mini by default, with Qwen 3.8 27B, Gemma 4 26B and Gemma 4 E4B on the drive. Reads photos. Starts a model that fits your RAM.

TAB 03

Library

All of Wikipedia with pictures, medical references, iFixit repair guides, Army field manuals and FEMA's emergency guides. All searchable.

kiwix-serve over about 40 ZIMs: Wikipedia maxi, WikiMed, iFixit, Army publications, Stack Exchange and LibreTexts. ./kit search finds more.

TAB 04

Map

Search an address, get driving or walking directions, or find the nearest hospital or pharmacy.

Protomaps tiles (world to z7, your region to z15), Photon geocoding and GraphHopper car and foot routing on a bundled JRE. The model can call them as tools.

01 · GET A DRIVE

A 2 TB external SSD and a Mac with an M chip (M1 or newer). 32 GB of memory runs the full-size AI; smaller Macs get a lighter one.

02 · FILL IT

Unzip the kit onto the drive and double-click SETUP. It downloads for a few hours and checks every file.

03 · TEST IT

Turn Wi-Fi off and double-click START-HERE. Everything should still answer.

04 · REFRESH IT

Every two or three months, double-click SETUP again. Only what changed downloads.

01 · CLONE

git clone onto an exFAT SSD. 2 TB leaves room; the default kit is about 300 GB.

02 · PLAN

./kit plan lists every item, version and size before anything downloads.

03 · SYNC

./kit sync resumes, checks published checksums and keeps each old version until the new one verifies.

04 · TEST

./kit test starts every server offline and checks each one answers. Sync again every few months.

Build your ownThe principles, for any AI to build from.
Help me build my own offline kit for an internet outage, on an external SSD. Principles:

- Everything works with zero internet: local AI models, an offline library and offline maps, served on localhost and opened in a browser.
- One config file lists every source. One command refreshes everything every 2-3 months. It resumes interrupted downloads, verifies checksums, and keeps the old version until the new one checks out.
- AI: a few open-weight models sized to my computer's memory (one capable default, one small and fast), run with llama.cpp's server.
- Library: Kiwix ZIM files (Wikipedia, medical references, iFixit, preparedness guides) served by kiwix-serve with full-text search.
- The AI answers from the library: it searches it, reads the top passages and cites them. It still works with the AI off.
- Maps: vector tiles for my region plus a low-detail world map, offline address search and offline directions. The AI can use them as tools.
- An offline self-test, and a one-page printed guide kept with the drive.
- Use exFAT so any computer can read the drive, and avoid symlinks.

First ask me about my computer, drive size, region and priorities. Then propose a plan before writing any code.

Questions

Before you fill a drive.

Is the AI as good as ChatGPT?

Not quite. It's an open model small enough to run on a Mac, so it's a step behind the biggest cloud AIs. It's good at explaining and summarizing, the Ask tab answers from the library with sources, and none of it needs the internet.

What do I need?

A Mac with an M chip (M1 or newer) and an external SSD. The kit itself is free. 32 GB of memory runs the full-size AI; smaller Macs use a lighter one. The recommended kit is about 300 GB, so a 2 TB drive leaves room to grow. The kit builder above shows the total for your picks.

What does it need?

Apple Silicon and macOS. Sync needs the Command Line Tools for python3 3.9+ and curl; running the kit doesn't need Python. 32 GB of RAM runs the default model, and below that the launcher starts a smaller one. The default kit is about 300 GB, so a 2 TB SSD leaves room.

Does anything leave my Mac?

No. Once the drive is filled, every part runs on your Mac at 127.0.0.1 with no account and no telemetry. The only time it goes online is when you run SETUP or ./kit sync to download updates, and then it only talks to the places it downloads from: GitHub, Kiwix, Hugging Face, Protomaps, Geofabrik, GraphHopper, Adoptium, Maven Central and npm, plus anything you add to kit.json.

Can I trust the AI's answers?

Treat it like a well-read friend, not a doctor. In the Ask tab it answers from the library and numbers its sources, so you can open the page it used and check. For anything serious, read the source itself.

Why llama-server and not Ollama?

One binary with an OpenAI-compatible API and a router mode that swaps models. Nightly builds run new models first, and there's no daemon or model store to manage on a drive.

What does sync check?

Each download against the checksum its publisher posts: Kiwix .sha256, Hugging Face LFS hashes, GitHub release digests, Maven .sha1, npm integrity, Geofabrik and Photon .md5. Map tiles have none, so pmtiles verify checks them. Downloads resume, and the old version stays until the new one verifies.

Why exFAT?

So a Windows or Linux PC can read the drive if the Mac is gone. exFAT has no symlinks or native file locks, so runtime versions use CURRENT pointer files and GraphHopper uses simple locks. If Photon can't lock its index there, ./kit test says so; APFS works too.

How do I add a book?

./kit search WORDS queries the Kiwix catalog and prints a line to paste into library in kit.json. Then ./kit plan and ./kit sync. Updates of the kit keep your changes.

Can my family use it from their phones?

Yes. Start it with --share and any phone on the same Wi-Fi or hotspot can open the page. No internet is needed for that, only a local network. Anyone else on that network can open it too, so share on your own hotspot or home Wi-Fi.

How long does it run on battery?

The big model uses a lot of power: expect a couple of hours of active use on a laptop. The small model uses much less, and the Library tab with the AI off uses almost nothing. A USB-C power station and a folding solar panel keep it going.

What about Windows or Linux?

The Mac is the supported setup for now. They're a fallback if the Mac is gone: on an exFAT drive, a Windows PC runs the library and a slower AI with the included launcher, and Linux runs it from Terminal. The map is Mac-only, and these paths are less tested.

Is all this content legal to download?

Yes, for your own use. The kit downloads everything straight from its publishers: Kiwix packages openly licensed sites like Wikipedia, WikiMed and iFixit, and US government guides, and the AI models are open-weight models published for anyone to run. Each keeps its own license, and some, like iFixit's, forbid commercial use, so don't sell drives you've filled. Every source and its license.
